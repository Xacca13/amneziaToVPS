## 📖 Обзор

### Что это?

Модульная система развертывания VPN-шлюза на базе AmneziaWG. Вместо монолитного скрипта на 2000 строк — **интерактивный установщик**, который:

- Спрашивает, какой режим работы вам нужен
- Предлагает выбрать опциональные компоненты
- Скачивает только нужные модули из GitHub
- Интерактивно настраивает списки маршрутизации

### 🎯 Преимущества модульного подхода

- **Гибкость**: Устанавливайте только то, что нужно
- **Экономия ресурсов**: Не ставьте Zapret, если он не нужен
- **Простота обновления**: Каждый модуль обновляется отдельно
- **Читаемость**: Каждый скрипт — 50-200 строк, а не 2000

## ⚡ Быстрый старт

### 1Запуск установщика одной командой

```
curl -sSL https://raw.githubusercontent.com/yourusername/amnezia-gateway/main/install.sh | bash
```

Или клонирование репозитория:

```
cd /root
git clone https://github.com/yourusername/amnezia-gateway.git
cd amnezia-gateway
chmod +x install.sh
./install.sh
```

### 2Следуйте интерактивным подсказкам

Установщик задаст вам 5 простых вопросов:

1. Режим работы (Мульти-конфиги / Каскад)
2. Публичный IP VPS
3. Какие локальные серверы запустить (Split/Full/Оба)
4. Опциональные компоненты (Smart Update / AdGuard / Zapret)
5. Источники списков маршрутизации

### 3Готово!

После завершения установки система полностью готова к работе. Используйте команду `vpn-help` для просмотра всех доступных команд.

### 💡 Как это работает

Когда вы запускаете `install.sh`, он:

1. Спрашивает у вас, какие модули нужны
2. Скачивает их через `curl` из папки `modules/`
3. Делает их исполняемыми (`chmod +x`)
4. Последовательно выполняет каждый модуль
5. Логирует все действия в `/var/log/amnezia-gateway.log`

### ⚠️ Важные замечания

- Все модули хранятся в репозитории GitHub — вы можете их просмотреть и модифицировать
- После установки все скрипты остаются на VPS в `~/amnezia/`
- Вы можете запустить `install.sh` повторно для изменения конфигурации
- Каждый модуль идемпотентен — его можно запускать многократно без побочных эффектов

## 🎯 Что дальше

### После установки

1. Загрузите конфиги провайдеров в `~/amnezia/clients/` (режим Мульти) или создайте конфиг каскада
2. Выполните `vpn-reload` для полного цикла настройки
3. Подключите устройства к VPN через конфиги из `~/amnezia/server-clients/`
4. Используйте `vpn-help` для просмотра всех доступных команд
